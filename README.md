# PCB Design for ESP32-Based Environmental Data Logger

This repository contains the KiCad 8.0 PCB design files and documentation for an Environmental Data Logger based on the ESP32. 

## Designed by
Vikram Reddy

## Tool Used
KiCad 8.0

## Board Features
- ESP32 DevKit V1
- DHT22 Temperature Sensor
- BH1750 Light Sensor (I2C)
- MQ-135 Air Quality Sensor
- OLED Display (I2C)
- Micro SD Card (SPI)
- 3.3V Sensor Power Rail
- Proper GND pour on Top & Bottom layers

## Project Structure
- **3D view**: Contains 3D renders of the PCB (Front & Back views).
- **Bom**: Bill of Materials in PDF and Excel formats.
- **Check**: Design Rule Check (DRC) and Electrical Rules Check (ERC) reports (No errors).
- **Pcd Layout**: PCB layout images and PDFs for Top/Bottom Copper, Silkscreen, and Edge Cuts.
- **Schematic**: Schematic PDF and screenshot.
